# B パーツ統合時のオブジェクト変更一覧

対象: `Assets/Scenes/HomeScene.unity` と `Assets/Scenes/GameScene.unity`。B のシーン・素材・モデルを採用し、A のバッティング処理と演出を接続した。

| オブジェクト | 変更・追加内容 |
| --- | --- |
| Terrain（B） | 60 × 90 m の地面を 210 × 190 m に拡張。左奥を `(-105, -0.18, -12)` に配置。芝色を調整。 |
| Floor（B） | 長方形の板を内野ダイヤ形メッシュに変更。B の `FloorBase` マテリアルを保持し、ホームから奥へ約 40 m の範囲に配置。 |
| HomeBase / HomeBase2（B） | 約 0.46 m 幅に調整し、プレイヤー付近の地面上に配置。 |
| WakuLeft / WakuRight（B） | 内野両側の境界材を各 27 m 長に調整。 |
| ピッチャー（B） | B のキャラクターを約 1.8 m 高に正規化。中央のほか左右に2体を追加し、3レーンに配置。静止時の腕姿勢と投球時の腕動作を調整。 |
| ネット壁4面（B） | B のネット素材・プレハブを使用。左右・後方・外野の各壁を 12 m 高でフィールド外周へ移動・拡大。不要な XR interactable を除去。 |
| B Field Markings（追加） | 芝の縞、ファウルライン、バッターボックス、3塁分のベースを追加。ベースは B の HomeBase を複製。 |
| B Lobby Accents（追加） | HomeScene の壁面に細い装飾ラインを追加。B の壁・床マテリアルと照明色も調整。 |
| B GameManager | A の `StageView` と `BatGame` を追加し、B の `GamePlayModule` に接続。B のフィールドを使う設定。 |
| 重複 XR・サンプル展示物 | GameScene 内の重複 XR Rig、XR シミュレーター、サンプルのインタラクタブル・UI・テレポート領域を無効化。HomeScene の XR Rig は維持。 |

Unity Game View のスクリーンショットで内野・投手3体・ネット・ホーム UI を確認した。投手の足元とホームベースは地面に埋まらず、ネット壁は外周で地面から立ち上がっている。実機 VR の手の届く範囲は別途確認が必要。
