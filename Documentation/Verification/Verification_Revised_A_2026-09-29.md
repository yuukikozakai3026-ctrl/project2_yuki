# 改訂A案の実装・検証（2026-09-29）

今回の基準は `Documentation/Revisions/VR_Bat_A_Revised_Implementation_Brief.md`。旧A案の固定軌道、単発限定、近距離ネットへの返球は廃止。プレイできるのはA案のみ。

## 実装した8種

| 対象 | 実装した動き・打撃結果 |
| --- | --- |
| 野球ボール | 発射口から最終打点へ直進。高速接近後、早めに減速し、打撃後は遠方へ飛ぶ |
| ケーキ | スロー中に横へ最大約0.72mカーブ。クリームの短い軌跡。スポンジ・クリーム・苺が前方のフィールドへ飛散 |
| 毒瓶 | 2回の横向き噴射で進路を折り返す。噴流と音は進路変更の約0.30秒前。打撃でガラスが前方へ割れ、煙は短時間で消える |
| ブーメラン | 右側（左利きでは左側）へ外れ、前方視界内で奥へ折り返して戻る。大きなU字軌道と回転 |
| 魔法球 | 3・5・8個。青寄りの本物1個と紫寄りの偽物。偽物の先打ちで得点を減らさず、進行を止めない。本物を打つと残りが浮きながら0.65秒で透過。本物を含む同時接触を優先 |
| 爆弾 | 導火線が4回小さく爆ぜ、反動で進路変更。明るい火花を約0.30秒先行。打撃後約68m先で爆発 |
| 銃弾 | 3発の実弾。0.13秒間隔、横のずれ0.16m。一振りで複数を弾け、各弾の接触・得点を独立して処理 |
| 宝箱 | 空中回転、蓋が開く間の浮上、閉じた後の落下。大きな箱の面を一打すると開封し、金貨・宝石が前方へ飛ぶ |

従来の花火球は今回の出現順から外し、必須8種に絞った。新たな台・配膳機・跳弾板は設けていない。近いネットと金属板を撤去し、スコア板は投球を遮らない左上へ移した。

## 改訂前後の基準値

改訂前の実行ビルドを `RevisedA_Baseline` で再生・撮影した。ログで中央の発射Z=7.38m、通常接近1.60秒を再確認。旧ソースは `Documentation/Revisions/BeforeRevisedA_Source.tgz` に保存した。

| 項目 | 改訂前 | 改訂後 |
| --- | --- | --- |
| 基準の通常接近速度 | (7.38−0.86)/1.60 ≈ 4.075m/s | 12.225m/s（3倍）。最後の0.055秒で減速 |
| スロー開始Z | 0.86m | 2.00m |
| スロー中の移動速度 | 0.40m/s | 経路長基準で0.40m/s。曲がる際も速度を維持 |
| 普通の球のスロー時間 | 本番0.90秒 | 約3.80秒。変則物は経路が長い分さらに長い |
| 打球 | 近い固定ネット等へ約0.60秒 | 基準68mのフィールドへ約2.60秒。破片や報酬も遠方へ飛ぶ |
| 強打判定 | バットの帯（握り基準0.43〜0.68m） | 維持。最低スイング速度なし。通常10点・強打20点 |

通常打と強打は同じ返球計算を使い、飛距離の引数に強打フラグを使用していない。強打では打撃音・衝撃粒子・振動を増やす。スローは飛来物の経路だけに適用し、HMD・手・入力・カメラをスロー化していない。PCデモも固定視点で、打球への自動追従をしない。

## 確認できた内容

- Unityの幾何チェック: 8種の前方経路、最後の到達位置、通常接近3倍、スロー速度、元の帯境界、静止バットへの接触を確認。
- 実際のバット接触判定を使うPCデモ: 8種すべてを打撃。魔法3・5・8個、偽物先打ち、5個/8個の本物を含む2個同時接触、通常打/強打、銃弾3発、見逃し、結果画面を確認。
- `Tools/verify_revised_a.py` がイベントログを検証し、得点を注入せずに全必須ケースを通過。`RevisedA_FinalReview/assertions.json` に結果を保存。
- 左利き・目線1.35mのPCデモでも8種と魔法球の全ケースを通過（`RevisedA_Left135/assertions.json`）。
- 録画なしの通常90秒プレイは240点で完走、平均58.41 FPS、実行ログに例外なし（`RevisedA_Normal90`、PCデモの待機姿勢の最終調整前）。
- 録画はPCの通常時間で15fps。録画用の追加描画とJPEG保存による負荷を含むため、録画中の平均FPSはVR性能の指標ではない。
- 画面評価エージェントの初回レビューで毒瓶の噴流と爆弾の火花の弱さを指摘され、噴射方向・点火の予告と爆弾の輪郭を修正した。さらにPCデモのバットが魔法5/8の下段を隠す点を修正。最終の連続画像レビューでは、これらの問題が解消し、新たなP1/P2の視認性問題なしと判定された。
- 音声付き映像で各反応を記録。リスナー出力にクリッピングなし。最終ビルドではVRのフレーム上限を固定せず、XRランタイム側へ委ねる（実機未確認）。

- 最終Macビルドの導入失敗テスト: ケーキを2回見逃した後、補助リトライで打撃し、カウントダウンから本番開始まで復帰（`RevisedA_IntroRecovery`）。実行ログに例外なし。
