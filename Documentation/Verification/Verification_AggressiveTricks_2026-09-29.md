# 特殊球の速度・動き・魔法弾の間隔調整

2026-09-29

## 最終仕様

- ブーメラン・毒・魔法弾：スロー域の移動速度を0.4→0.6m/s（1.5倍）、遠方の特殊動作を1.8→2.3m/sへ変更。他の種類は従来の速度。
- ブーメラン：横の回り込みを1.28倍、回転を250→330度/演出秒へ。近づいても止めず、帰り道に余分な逆向きフックを加えない。
- 毒：横方向の反動を約1.57倍。最初は約3.34m、最後は約1.04mの2回。約0.3秒前の噴射予告を維持し、予告のない追加方向転換を行わない。
- 魔法弾：4.2mから滑らかなS字で流れながら近づく。同じ群の並びは保ち、直前の入れ替え・追尾補正は行わない。3発の横間隔30cm、5発の配置半径は横36cm/縦20cm、8発は横28cm/縦27cm。魔法群の中心は1.34m、可変打点込みで球中心の高さ1.06〜1.62mに収める。本物と偽物の差は小さな明るさ・色味だけ。
- ケーキは打撃直前まで曲がり、宝箱は上下動・蓋開閉を続ける。毒・ブーメラン・箱の接近による回転停止を廃止。スロー中も低速で動き続ける。
- 金帯限定の接触判定、速度下限なし、先端押し込み拒否、スロー域1.49〜0.48m、90秒ルール、68m返球、短いクールダウンを維持。
- デモも実際の金帯判定を使用。ケーキの面にバット側面を合わせ、箱の待機中はバットを横へ退避。魔法の偽物→本物への切り返しを新速度に合わせた。

## 実行と検査

- 高さの最終調整前の全種スイート `AggressiveTricks_FinalSuite`：全8種類、魔法3/5/8発、偽物から本物への切り返し、意図的な最後のミスを含み260点。8検査成功。
- 最終版 `AggressiveTricks_Release`：導入2種＋通常90秒21投、500点、予定外のミスなし。全8種類と魔法3/5/8発を実接触で検査。7検査成功。
- 各種33パターンの軌道連続性、魔法群の球間距離20cm以上と到達範囲、予告付きの毒2反動、ブーメランの帰路、全8形状の先端押し込み拒否を両ビルドで検査。
- スロー演出時計は通常時計の20%。全種の帯接触・返球・短いクールダウンを確認。実行ログに例外、シェーダーエラー、参照エラーなし。
- Mac版・Windows OpenXR版のビルド成功。録画はデスクトップ版の一人称画面と音声を直接記録。

## 画面レビューと対応

- 別エージェントが連続画像を評価。毒の噴射と進路変更、ブーメランの回り込み、魔法群の分離と控えめな色差を確認。不自然な停止・追加フックは見つからなかった。
- 球間隔を広げた初版では、低い魔法群の最下球が近距離で画面下に切れた。原因は演出方式ではなく、従来の低い中心位置を残していた配置設定。中心と縦の半径を調整し、低い可変打点でも再検査した。
- 最終04/16（5発）、08（8発）、10（3発）を再評価。最低寄りの5発でも接触直前の下端余白約30px、通常の5発は約50px。8発の上段も見切れず、3発も接触前に全体を識別できた。接触姿勢のバットによる一時的な遮蔽を除き、重大な見切れ・新たな重なりなしと評価。
- 箱は待機バットを退避して開閉が読み取れる。ケーキも金帯と表面が自然に接することを確認。
