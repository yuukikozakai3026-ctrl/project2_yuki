# VR入力とPC自動デモ

## 1. 二つの入力元、同じゲーム

ゲームへ渡す入力は頭の位置・向き、左右手の位置・向き、メニュー用ボタンだけ。VRは実機、PC自動デモは予定した姿勢列からこれらを供給する。デモから対象へ成功命令、得点追加、箱開封命令、爆弾の座標変更を送らない。バット・手・頭の見た目も同じものを使う。

入力アダプター、補間、時刻同期、衝突を取りこぼさない方法はCodexの技術的裁量。最終的な可視バットの軌道とルールを守る。デモが失敗した場合は実際の失敗を表示し、原因を直す。接触していないのに成功に見せる補正で済ませない。

PCでヘッドセットなしの起動時はAの自動デモを開始。右上に切替「A / B」を常時表示し、選択時だけ現在課題を破棄して選んだ案の導入から再開する。ボタンは右端32px/上28px、各幅56/高36px。「自動デモ」表示は共通指定の左上。VR接続時は自動操作を無効にして開始メニュー。明示したデモモードでVR機器の手を勝手に動かさない。

一時停止で全体時計・対象時計・自動姿勢をまとめて停止する。VR追跡が途切れた場合も同じ停止にし、再捕捉後は「続ける」の選択で復帰する。頭の追従は可能な間は維持。再開時に停止中の移動を一括で打撃にしない。これは通常の失敗や時間切れとは別の中断処理。

## 2. デモ姿勢の規約

単位m。すべて右利き基準、H=1.65。バットの方向ベクトルUはグリップから先端へ向く単位ベクトル。グリップGと軸Uに対し、軸上の点は`G+sU`。局所Yのs範囲は-0.12〜0.73。全体の回転はこの軸と上向きから作り、必要なロールは0°。左利きではXを反転し、手を入れ替える。

待機姿勢：グリップG=(0.28,1.05,0.20)、U=(-0.25,0.60,0.759934)。非利き手=(−0.22,1.05,0.18)。利き手が手前へ戻る際にも物体や台を貫通しない。全経路は位置連続・速度連続の補間を使う。移動の始終で速度0となるsmootherstepを基準にし、急に方向が変わる角を作らない。

PC頭部は位置(0,1.65,0)固定。通常は正面から下へ10°。cakeでは下18°/右8°、bombでは下22°、chestでは下12°へ0.6秒で移る。終了後0.6秒で通常へ戻る。横レーンではyawをレーン側へ最大8°。視点位置の移動・カット・球を追うズームなし。実際のVR視点へこの自動角度を適用しない。

## 3. Aの手の動き

対象の実際の中心を基準にするが、指定軌道上の予測接触点を計算して手を準備する。予告中は目標点の20cm手前へ移り、通常接近の最後0.35秒で以下の準備点へ入る。

U=(-0.65,0,0.759934)。帯成功はs=0.555、通常成功はs=0.32。接触予定点Q=(laneX,Y,0.70)とし、`G_hit=Q-sU`。

| スロー開始から | グリップ位置 | 意味 |
| --- | --- | --- |
| 0.00秒 | G_hit+(0,-0.08,-0.10) | まだ物へ触れない準備 |
| 0.35秒 | G_hit | 物の経路へバットを入れる |
| 0.65秒 | 同位置 | 接触を待つ。高速振りはしない |
| 解決後0.25秒 | 待機姿勢への中間点 | 奥へ振り抜かず次へ戻す |

球の半径とバットの太さにより、初接触は点Qそのものに一致しなくてよい。接触位置が指定の帯/帯以外にあることを確認する。スロー中に成功したら、以後の手の帰還を自然につなげる。早く成功しても対象の演出を早送りしない。

本番n=0,2,4,6,8は帯、それ以外は通常と帯を交互にする。**n=10の普通のボールだけ意図的に見逃す**。その際G=(0.28,0.95,0.12)、U=(0.25,0.60,0.759934)として対象の経路を空け、回収まで維持。次から通常の手順へ戻る。見逃すために球の当たり判定を消さない。

導入は4段階約17秒＋本番開始の3秒。最初の球は少し待ってからバットを出し、広い帯内に置く。2球目は帯、cake/fireworkは通常成功。導入の実演条件を満たさなければ機械バットは動かない。20秒ぴったりへ映像を切る必要はない。

## 4. Bの手の動き

本番の一課題あたりの時間目標は、予告から次の予告までの実時間。物理の結果を映像時間へ合わせて強制しない。予定と大きくずれる場合は経路・接触時刻の実装を確認する。

### ボール

Aと同じ姿勢計算、QのZだけ0.74、スロー開始0.30〜0.40秒に接触する軌道。本番のボールは通常/帯を交互にする。所要約3.35秒。

### ケーキ

U=(-0.10,0,0.994987)、捕捉軸位置s=0.50。皿底Pに対し、軸の接触予定点は`P+(0,-0.064,0)`。`G_catch=P+(0,-0.064,0)-0.50U`。

| 到着Pからの時間 | 動き |
| --- | --- |
| 0.00 | G_catch+(0,-0.10,-0.02)。バットは皿の下 |
| 0.20 | G_catchへ上げ、皿底へ実際に接触 |
| 捕捉後0.20秒 | 皿底をY1.17へ0.07m持ち上げる。バットがフォークを越える高さを作る |
| 捕捉後0.65秒 | 皿中心XZを(0.58,0.62)へ移動。皿底Y1.17を維持 |
| 捕捉後0.95秒まで | 皿底Y1.13へ0.04m下げ、dock成功範囲へ入れる |

捕捉時刻がずれた場合は捕捉確認後に運び始める。未捕捉のまま持っている芝居をしない。sの実接触位置が目標からずれても、それを用いて同じ皿の経路となるグリップ位置を算出してよい。これは入力経路の計算であり、皿の瞬間移動ではない。所要約4.85〜5.05秒。

### 爆弾

押したい水平単位方向dに対して、バットは接線方向に横向きに置く。t=(d.z,0,−d.x)を取り、t.zが負なら符号反転する。U=t、接触軸位置s=0.43。球中心Y0.99、軸のY1.08、球半径0.11＋バット半径0.039なので、水平離隔は`h=sqrt(0.149²−0.09²)=0.1186648m`。実際の球中心XZ−h×dを軸接触点XZとし、グリップG=軸点−0.43tで求める。これで3D空間で球とバットの可視面が接する。

非接触の準備位置はさらにdの逆へ0.05m離す。向きを変える時はまず球から0.07m離れてから回す。押す方向へ接近しながら姿勢を瞬間変更しない。軸Y1.08によりバット下面Y1.041となり、台の縁および受取フォーク上面Y1.02を越える。接触面の連続検出を使い、最初から球へ重なった姿勢を与えない。

最初の爆弾は、着地後0.20秒で球の右手前へ斜めに触れ、d=(-0.707107,0,0.707107)として奥左へ少し逃がす。0.35秒かけてバットを球から0.07m離し、球の現在位置と穴中心を結ぶ方向の反対側へ回り込む。続く0.80秒で接触を維持して左手前へ押し、最後の0.30秒は穴へ落ちるのを待つ。所要約1.8秒の卓上操作を目標とする。

2回目は同じ当て直しを一度含めるが、大きな追跡遅延を入れない。押す向きは実際の球の位置から決めてよく、手の移動は連続にする。球の移動速度を上書きして予定点へ送り込むことは禁止。解法がエンジン間で違う場合は経路の補間方法を直し、穴・球・期限を変更しない。

3回目は意図的な期限切れを見せる。着地後0.8秒に一度だけ球を奥側へかすらせ、以降はバットを台上の球から離して待つ。8秒の導火線、覆いの回収を実時間で見せる。爆弾を難しい場所へ直接移動させない。覆いが出たらG=(0.28,1.15,0.18)へ戻す。

### 銃弾群

グリップG=(0.40,1.24,0.59)、U=(-0.995,0,0.099875)。バットの長い部分が列に沿うよう、スロー開始0.10秒までにこの姿勢へ入る。弾群のZ移動によって複数が実際に当たる。軽い斜めの列ではU.yを列と同じ傾きに合わせ、長さを変えず正規化する。

1回目は全弾。2回目だけG.xを+0.25mへ動かし、左端の一発を取り逃す。狙いどおり部分接触にならなければ可視バットと球の接触を確認し、非接触を偽造しない。3回目は4発全弾。バットを保持して接触させる方式なので、速さを示すスイング演出を追加しない。

### 宝箱

U=(-1,0,0)。グリップの接触側は(0.40,1.24,0.44)、退避側は(0.40,1.24,0.20)。到着から約0.15秒で1打目、退避→2打目を約0.60秒、退避→3打目を約1.05秒。接触受付の光が出たことを確認して次へ進む。箱が勝手に揺れてバットに当たっただけで打数が増えてはならない。

実際の接触で箱が先に解決した場合は自然に帰還。受付を待つために遅れた場合もそのまま見せる。3打を帳尻合わせで増やさない。

## 5. Bの時間割と導入

右利き基準で、最初の一巡は約32秒。最初の宝箱の開封は35秒以内を目標とする。二巡目の弾群の一発逃しは35〜65秒。三巡目の爆弾の期限切れは約85〜88秒、続く弾群が復帰場面となる。全体の終了処理は仕様どおりで、90秒に間に合わない最後の弾群も本来の接触機会を保証する。

これはタイムコードで対象を出す動画ではない。一巡目の時間目標は次の通り。実装時は実測ログと照合する。

| 順番 | 種類 | 予告開始〜次の予告の目標 |
| --- | --- | --- |
| 1 | ball | 3.35秒 |
| 2 | cake | 4.95秒 |
| 3 | ball | 3.35秒 |
| 4 | bomb | 5.40秒 |
| 5 | bullets | 3.35秒 |
| 6 | ball | 3.35秒 |
| 7 | chest | 4.85秒 |
| 8 | ball | 3.35秒 |

導入の自動プレイヤーは約40〜50秒で6課題を体験する。ballは広いスローを見せる。cakeは到着後3秒迷ってから下受けし、約1秒で配膳（導入なので期限なし）。導火線なしbombは3秒待ってから押す。chestは一打目の後1秒観察してから残りを打つ。背景実演が必要になる条件もそのまま機能させる。必要な場合だけ見本が動く。初回メニューを約3秒見せ、最後に3秒の開始ランプを含める。人間の導入へこの待ち時間を押し付けない。

結果6秒→同じ案の初回導入へ戻る。総得点・個別期限・残った演出・機械の状態をリセットする。A/B切替は別ゲームの開始として扱い、爆弾・皿・箱の途中状態を持ち越さない。
