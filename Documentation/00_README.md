# VRバットゲーム A・B — Codex向け作成指示書

版：1.0／2026-09-28。基準：A・Bゲーム仕様書 v1.1。これは実装を依頼するための資料であり、ゲームの完成品ではない。

## 実装するもの

一つのプロジェクト内に、独立した二つのゲームを作る。

- **A「バット・カーニバル」**：5種類の物をすべて一打で処理する。狙った場所で当たった瞬間の気持ちよさが中心。
- **B「バット・ワークショップ」**：ボールは打つ、ケーキは受けて置く、爆弾は転がす、銃弾群はまとめて弾く、宝箱は3打で開ける。扱いの切り替えが中心。
- 本物のVR入力と、頭・手の動きを供給するPC自動デモを用意する。自動デモにも実際の接触判定を通す。

仕様・配置・素材・色・演出・UIは本資料で決定する。Codexは環境設定、コード構成、互換性対応、計算方法、性能改善の実現方法を判断してよい。ゲームの調整を「技術的裁量」として行わない。

## Codexへそのまま渡せる依頼文

> 同梱の作成指示書一式に従い、AとBを独立したゲームとして実装してください。最初に01〜07とscene_layout.jsonを読み、既存環境を確認してください。ゲームの仕様・見た目・寸法・画面配置・演出は指示書どおりにし、環境対応・実装構成・バグ修正・見た目を維持した性能改善は判断して進めてください。Kenney素材は添付カタログの運用に従い、このプロジェクト用に公式配布元から新規取得してください。素材をダウンロードしただけで完了とせず、指定場面に組み込み、PC自動デモをループ再生できるところまで完成させてください。VR機能も組み込んでください。実機がなければ実機テスト済みとは報告しないでください。確認が必要な仕様上の矛盾は箇所を示し、影響のない作業を先に完成させてください。

## 指示書で固定した主な数値

基準目線1.65m、バット全長0.85mと帯0.25m、B作業台1.60×0.80m、廃棄穴直径0.44m。94個の配置物（床56枚を含む）と動作地点はlayouts/scene_layout.jsonに記録した。台はケーキを受けた時だけ中央が開き、バットの通路を作る。

## この資料の確認範囲

Kenney公式7パックを新規取得し、実ファイル・ライセンス・主要モデルの構造と寸法を確認した。ケーキの分割ノード、宝箱の開閉アニメーション、外部テクスチャ依存を確認している。参考画像は配布物から作った静的な確認図。座標・素材の静的検査60項目は通過。Unityへの導入、VR実機、完成ゲームの画面、音の試聴は未確認である。

このZIPにはKenney素材本体を再配布していない。制作時に公式から取り直す運用を守るため、採用一覧・参照図・ライセンス記録のみを入れている。
