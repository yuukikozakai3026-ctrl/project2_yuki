# A 作成指示 — バット・カーニバル

## 1. ルール

すべての物を一打で処理する。バットの帯なら20点、他の可視部分なら10点、見逃し0点。種類による点差はない。接触の最初の一回で結果確定、破片や打ち返した本体に得点判定を残さない。受ける、避ける、連打する操作を混ぜない。

90秒、失敗減点・ライフ・コンボ・延長なし。終了と次の供給の規則は共通指示どおり。結果の「打てた数」は通常成功+帯成功、「帯の数」はその内数。

## 2. 操作対象のモデル

すべてcenter基準。3Dモデルの正規化と加工は04・06を参照。

| ID | モデル | 閉状態の寸法(X,Y,Z)m | 基準姿勢 |
| --- | --- | --- | --- |
| A_ball | Pirate `cannon-ball.glb`を白い野球球へ加工 | (0.14,0.14,0.14) | 赤い縫い目が見える、回転しない |
| A_cake | Food `cake.glb`のscene root node index=0だけ | (0.30,0.2563,0.30) | 元の上を+Y、切断面を手前、皿なし |
| A_firework | Pirate `cannon-ball.glb`＋金帯と星 | (0.22,0.22,0.22) | 青緑地、星が-Z、導火線なし |
| A_bullet | Pirate `cannon-ball.glb`加工 | (0.14,0.14,0.14) | 銀色の丸い玩具弾、先端を尖らせない |
| A_chest | Pirate `chest.glb` | (0.30,0.27,0.30) | 錠前-Z、水平、閉じて飛来 |

Aのケーキに皿を付けない。Aの花火弾に導火線を付けない。Bとの操作の違いを外見で区別するための固定事項。

## 3. 発射・接触点・軌道

投球番号nは本番開始後0から増える。順序は`[ball,cake,ball,firework,ball,bullet,ball,chest]`を繰り返す。時間区分は予告開始時の本番経過時刻で確定し、その一投の途中では変更しない。

| 経過時間 | 接触レーンの順序 | 接触Yの順序 | 通常接近時間 |
| --- | --- | --- | --- |
| 0〜30秒未満 | C,C,C,C,C,C,C,C | 1.22固定 | 1.60秒。bulletだけ1.40秒 |
| 30〜60秒未満 | C,L,C,R,C,L,C,R | 1.22,1.10,1.22,1.30を反復 | 同上 |
| 60秒以降 | C,L,R,C,L,C,R,C | 同上 | 1.40,1.80,1.60,2.00を反復。bulletは1.40秒 |

各配列はその区分に入った最初の投球を添字0とする。レーンXはC=0、L=-0.30、R=+0.30。接触の代表点`T=(laneX,Y,0.66)`。入口はC/L/Rに対応するmuzzle。全ターゲットへdyを加え、左利きではX反転。

1. 予告0.80秒：発射口の扉が0.25秒で外へ開く。入口のリングが1回だけ明るくなり、発射待ちの物の形を見せる。
2. 発射口中心から`S=(laneX,Y,0.86)`へ通常接近。基本は直線。ケーキと箱だけ、進行率uに対して高さに`0.14×4u(1-u)`mの山を加える。
3. S到着で対象だけスロー。`S→E=(laneX,Y,0.50)`を0.90実秒で進む。表示上の速度0.40m/s、通常換算2.0m/s。接触の代表点Tは開始0.50秒後。終端まで速度を変えない。
4. 成功したら直ちに通常の時間感覚で成功演出。接触せずEまで来たら見逃し確定。対象が接触帯にいる間にスローの時間上限だけで加速させない。

通常部分の最後0.12秒で速度を連続につなぐ。Hermite等の補間方式は選んでよいが、始終点、所要時間、山の高さ、最後の接触帯は変更しない。飛行中のスピン、左右の蛇行、消失・複製は加えない。

### 打ち返し・回収

打ち返しの進路は入力と無関係に固定。工場の発射機と得点板の間の空いた通路を通るため、接触点Pから以下の中継点Q、終点Dへ0.60秒で進む。P→QとQ→Dの所要時間は各0.30秒、折れ目は接線が連続するよう曲線補間。軌道を変えて投球機を突き抜けない。ケーキと箱はPで分解を開始し、破片は奥へ飛ばす。

| 対象 | 中継点Q | 終点Dと結果 |
| --- | --- | --- |
| 球 | `(0.82,1.70,3.00)` | `(0.92,1.50,5.48)`、半径0.07mの球がfar_collector前面Z5.55に接触 |
| 花火弾 | `(0.82,1.70,3.00)` | `(0.92,1.80,5.10)`、ここで丸い花火を開く |
| 単発弾 | `(-0.82,1.70,3.00)` | `(-0.90,1.50,5.40)`、半径0.07mの前端がmetal_target前面Z5.47に接触して鳴る |

左右レーンでも同じ中継点を通る。左利きはP/Q/DのXを鏡映する。固定通路はX=±0.82付近で、中央発射機の外縁X±0.425と斜め発射機の内縁X±1.225の間を通る。対象は得点板の下を通過する。中継点では背景物と重ならず、操作が必要な前景には戻さない。

見逃し確定後は、受け止め用の薄い半透明チューブが対象の下に0.15秒で現れ、対象を側方へ運んで背後のネットへ回収する。右レーンは右へ、それ以外は左へ。経路の点はE→`(sign×0.95,0.95,0.38)`→`(sign×1.05,0.95,-0.35)`→`(sign×0.8,0.95,-0.78)`、全体0.80秒。最初の区間はZ≥0.38を維持し、Xが±0.85へ達してから背後へ回る。dyを加える。

チューブは#9DBDC5、透明度0.18、内径0.40m、線の縁2本のみ。見逃した物を顔や胴体へ貫通させない。次の予告は共通の0.60秒後に始めてよく、回収末尾と重なる対象は半透明・非操作物にする。花火弾の見逃しで爆発は出さない。

## 4. 初回導入

本番時計なし。順番はball→ball→cake→firework。最初の2球のスローは1.80秒（S/E不変）、cakeとfireworkは0.90秒。1段階目は帯へ流れる光、2段階目は球と帯の0.8秒周期の明滅。帯以外でも成功なら進む。

同じ段階で2回失敗したら背景実演を2.5秒、一度だけ実施。実演後の本人の一回だけスロー1.80秒にして、成功・失敗どちらでも次へ進む。実演の間、手を制御したり画面をロックしない。いつでも「開始」で導入を省略できる。

実演バットのグリップは背景台上`(1.90,1.18,2.10)`、軸=(-1,0,0)。見本の球を`(1.62,1.18,2.45)`から`(1.62,1.18,2.10)`へ1.2秒で送る。バットを0.20m奥から手前へ0.45秒で動かして接触し、残りで小さな成功演出。Aのcake/fireworkも同じ動作で打つ。接触後の演出は04の0.65倍。

本番で同じ種類を2回続けて逃したら、次のその種類で発射リングと帯の明滅を1回追加するだけ。タイミング・当たり判定・得点を変えず、実演を挟まない。

## 5. 完成時に必ず見えること

通常接触でも明確な音と物の変化がある。帯での成功はそれに金色の衝撃輪が加わる。単なる無音の消滅で処理しない。五種類の違いは04の指定演出で出す。球の微細な命中位置、バットの速度、強い振りをゲーム側が要求してはならない。
