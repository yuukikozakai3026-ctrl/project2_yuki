# VRバッティングゲーム A案 改訂実装指示書

作成日：2026-09-29  
対象：現在制作中のUnity製3D VRゲーム、A案

## 1. この指示書の位置づけ

この文書は、従来の `VR_Bat_A_Game_Spec.md` と `02_A_Implementation.md` の**A案に関する改訂指示**である。両者と矛盾する場合はこの文書を優先する。特に、飛行中の複製・変則移動の禁止、打席の近くのネットへ固定経路で打ち返す指定、すべてを単発の物として扱う指定、従来の通常接近速度・スロー開始位置は撤回する。B案をこの文書で変更するものではない。

**目標は、打席に立ち、高速で飛んできた物の動きを見て、VRのバットで打ち返すゲーム**である。台上の物を押す・運ぶ・配膳するといった操作にはしない。飛来物の違いが投球の動きとして体験できるようにする。

## 2. 必ず守るゲーム上の条件

- 通常飛行の速度は、現在のA案で実装されている通常接近の**約3倍**を基準とする。数値の比較対象は実際に動いているビルドとし、旧文書の秒数をそのまま最終目標とはみなさない。
- スローモーション中の**飛来物の移動速度は現在のペースを維持**する。スローへ入る位置を打席から遠ざけ、打てる位置までの移動距離と**スロー時間を延ばす**。高速接近からスローへの転換がはっきり見え、スロー中に各アイテムの動きを観察して打てること。開始距離や継続秒数はVRでの見え方に合わせて調整してよい。HMD・手の動き・入力をスローにしない。
- **既存の強打判定を残す。**通常打と強打で打撃音・衝撃エフェクトの規模を変える。得点ルールが既にある場合は整合を保つ。**強打かどうかで打球の飛距離を変えない。**この文書を理由に新しい最低スイング速度や細かな狙い位置を要求しない。
- 打ち返した球や飛散物は、視界の奥のフィールドへ**十分遠くまで飛んでいく**。近距離のネットや収集機に毎回すぐ当てて終わらせない。通常打でも遠くへ飛ぶ。プレイヤーの視点を自動で追従・移動させない。
- 打席前の視界は投球と打撃が主役。飛来経路に設備や表示物を重ねない。個々のアイテムの動きを成立させるために、台、跳弾板、配膳機など**ステージ側の仕掛けを追加しない**。ステージの外観の整理・磨き込みは任せる。
- どの対象も基本はバットで打つ。外したり偽物を先に打ったりしても、不必要な罰や操作の中断を生まない。初見で分かる手掛かりは、物の姿、動き始め、音、短い軌跡などゲーム内の自然な反応に含める。長い操作説明や照準合わせを要求しない。

## 3. 必ず追加する飛来物

各行は**体験上の必須条件**である。見た目の細部、軌道の寸法、速度変化の補間、接触判定、音・粒子素材の選択は実装担当が調整してよい。すべての変化はプレイヤーの前方で見え、最後はVRで無理なくバットが届く範囲を通ること。

| 飛来物 | 必ず体験できる動きと打撃結果 |
| --- | --- |
| 普通の野球ボール | 素直にまっすぐ飛ぶ基準の投球。打てば遠くへ飛ぶ。変則的な野球ボールを別球種として増やさない。 |
| ケーキ | 飛行中に**大きくカーブ**する。クリームの軌跡や姿勢で曲がる方向を読めるようにし、打つと前方へ気持ちよく砕ける。受け取る・配膳する操作はない。 |
| 毒瓶 | 漏れた煙の**噴射と反動で進路が二段階に折れ曲がる**。噴射の向きと音で次の移動が分かる。打つと割れ、煙はプレイヤーの視界を長く塞がない。 |
| ブーメラン | 打席の脇へ外れるように飛び、**視界内で大きくUターン**して打てる範囲へ戻る。戻る前に見失わせない。 |
| 魔法球 | **3個・5個・8個**の球が群れとして飛来するパターンを用意する。1個だけ**少し色の違う本物**で、残りは偽物。偽物を先に打っても問題なく、その偽物は軽く消える。本物を打つと残りの偽物が**ふわっと消える**。すべてが本物のような罰付き判別ゲームにしない。複数同時接触で本物が含まれた場合は、本物の成功として処理する。数の多い群れも視界・打撃範囲に収め、必要な接触機会を与える。 |
| 爆弾 | 導火線が飛行中に小さく複数回爆ぜ、**その反動で急に進路を変える**。火花を動きより先、または同時に見せる。打つと遠方まで飛んでから爆発する。打席近くでの大きな爆発や視界を覆う閃光は避ける。 |
| 銃弾 | **3発が短い間隔で、少し位置をずらして飛んでくる**。3発とも実体で、一振りで複数をまとめて弾ける配置と間隔にする。個別に打ってもよい。魔法球とは「全部が本物」で区別する。跳弾させるためのステージ設備は作らない。 |
| 宝箱 | 空中で回転しながら落ち、**蓋が開くと少し浮き、閉じると落ちる**。大きな面を一打で打てる。打つと箱が開き、報酬が派手に前方へ飛ぶ。錠前など小さな部位を狙わせない。 |

お金袋は現時点で必須にしない。傘、ロケット花火などの追加アイテムも必須ではない。新しいアイテムを思いついた場合は、上の必須8種と打席の体験を完成させてから検討する。**ステージ設備や別操作を必要とする追加は行わない。**

## 4. 実装担当の裁量

従来の座標レベルの固定指示はA案の見直しを妨げないようにする。球の発射位置、投球順、カーブ量、スロー開始位置、打席の広さ、モデル・配色、背景、演出、音量、接触判定、Unity上の実現方法は、上記の体験を満たす範囲で担当者が決めて改善してよい。既存の素材サイトのカタログや取得手順を利用できる場合は、適したモデル・音・粒子を積極的に使う。指定素材を使うこと自体より、物の読みやすさ、統一感、打撃の迫力を優先する。

**外見を整えるだけで終えず、飛来速度、スローの入り方、バットとの接触、打球を見送るところまでを一続きの体験として仕上げる。** 強打判定の方式と既存の実装・入力環境はまず確認し、変更が必要なら理由を作業報告に残す。VRの頭と手の追跡、当たり判定、性能、酔いにくさについては技術的な方法を自由に選んでよい。

## 5. 改善と確認の進め方

1. 現在のAビルドを短く記録し、通常飛行速度、スロー開始地点と継続時間、打球の見え方、強打判定を確認する。旧文書の矛盾する固定座標や禁止事項を実装から取り除く。
2. 普通のボールで「高速接近→早めのスロー→打撃→遠方への打球」の一連の流れを成立させる。視点から実際に見て、迫力と打てる余裕が両立するまで調整する。強打と通常打の飛距離を同じに保ち、音・エフェクトの違いを確認する。
3. ほかの7種を実装する。各種について、**初見で次の動きを予想できるか／打てる位置に来るか／ほかの種類との遊びが違うか**を一人称の通常速度の映像で確認して修正する。特に魔法球の8個と銃弾3発が、見えない・届かない・処理時間が足りない状態にならないようにする。
4. 可能なら説明なしの初見プレイで、何を打てばよいか、ケーキ・毒瓶・ブーメランの行き先、魔法球の本物と偽物の反応が伝わるか観察する。実機確認ができなければPC上の自動デモや録画で代替した範囲を明記し、VRで未確認の点を残す。必要な手掛かりやタイミングを直し、固定の説明文を増やすことは最終手段とする。
5. 最後に、8種それぞれの飛来から打撃まで、通常打・強打、魔法球の偽物先打ちと本物への同時接触、見逃し、結果画面を通して確認する。変更内容と未解決点を、短い動画または連続画像とともに報告する。

細部で迷った場合は、元指示書の座標への忠実さより、**VRで球が高速で迫り、動きを見て打ち、遠くへ飛ぶ気持ちよさ**を優先する。ただし、上記の必須8種・魔法球の正誤反応・速度とスローの関係・強打時の飛距離固定・ステージ設備を増やさない条件は変えない。
