# 見た目・モデル加工・演出の指定

## 1. 採用する外観

テーマは白い金属バット、明るい工場のおもちゃ、食べ物と木箱の低ポリゴン造形。Kenneyの面の分かれる形を残す。対象の判別を妨げる輪郭の細かい追加、写実的な傷、リアルな銃、血、人間の敵は追加しない。

| 用途 | sRGB色 |
| --- | --- |
| 明色金属、球 | #E7EEF0 / 球#FFF9EE |
| 帯・成功輪・金貨 | #F6C850 |
| 黒い爆弾 | #28313C |
| A花火弾・皿と受取台の模様 | #31A9AC |
| UI地、グリップ | #294551 / #344556 |
| 赤い縫い目、イチゴの補色 | #D65357 |
| 宝石 | #55D4D0、英雄となる大宝石だけ#7DDCFF |

自然物のケーキ・イチゴ・宝箱はKenneyの元パレットを維持する。共通指示で指定した背景の乗算色以外、パック全体のテクスチャを上書きしない。球/爆弾/弾は別材質を割り当てる。加工前素材を残す。

## 2. モデルを座標へ合わせる手順

配布物のメッシュ、ノード階層、アニメーション、依存テクスチャを含めて読み込む。空の正規化ルートの子に元モデルを置き、見える閉状態の外接箱を測る。指定したcenter/bottomへ原点を合わせ、指定した実寸へ合わせる。原点合わせと回転でアニメーションのヒンジを壊さない。

| 対象 | 固定した加工 |
| --- | --- |
| cake A | `cake.glb`のscene root index 0（同名sliceの最初のノード）だけを残す。子の既存変換を含めた外接箱中心で再中心化、最大水平寸法0.30mへ等比縮小。両方の切断面のうち面積が大きい方を-Zに向ける。両方同じなら元ノードの+X向き面を-Zへ向ける |
| cake B | 全6ノードを残し、元の位置関係を維持。水平直径0.34mへ等比縮小、bottom基準。皿は別モデル |
| plate | `plate.glb`を直径0.44へ等比縮小。高さ約0.0444m、元の上向き。皿底に厚さ0.025mの受け金具を追加 |
| chest A/B | 本体とlid階層を維持。幅A0.30/B0.45へ等比縮小。錠前-Z・ヒンジ+Z。`open`アニメーションの終端を保持。Aは0.30秒、Bは0.35秒へ再生時間を合わせる |
| round objects | `cannon-ball.glb`の球を各軸の外接径が指定直径になるよう正規化。原点center。球に見える面取りを残し、球以外の部品は再利用しない |
| background machines | 正規化ルートの前面-Z、上+Y。指定した高さだけの場合は等比、それ以外は指定箱寸法へ合わせる |

球の縫い目は赤い太さ0.003mの線2本。球面上の局所パラメータt=0〜2πに対し、一方を`normalize(cos(t),0.45 sin(2t),sin(t))×(r+0.0005)`、もう一方をそのY軸90°回転とする。細い斜めの縫い糸16本を各線へ等間隔に置く。文字・照準のようなマークは付けない。

A花火弾は球の赤道に幅0.04mの金帯。正面に五芒星、外接径0.095/内径0.045m、厚さ0.001m。B爆弾は導火線を球上端から奥右へ曲げ、全長0.18m、半径0.006m。導火線は8秒で先端から短くなる。消えている導入弾は灰色の芯で火花なし。

金貨は12角円柱、直径0.045/厚0.006m、両面に直径0.025mの浅い円。宝石は上下を尖らせた8面体、寸法0.065×0.09×0.065m。開封時の大宝石は0.12×0.18×0.12m。これら、バット、クランプ、正確な穴を持つ台は指定形状を制作する。装飾まで全てをプリミティブへ置き換えることは認めない。

皿の保持金具は淡い金属#A7BEC5。捕捉前のクランプは外へ35°開き、捕捉後0°へ閉じる。バット回転に対して皿を水平に保つジンバルの軸リング直径0.12/太さ0.008mを皿の下に表示する。支持支柱は太さ0.012m、平常長0.025m、可動長最大0.95mの3段伸縮。03の非貫通規則で必要な分だけ伸び、段の境界を濃色リングで見せる。受取可能面の見た目を大きくし、作業台の穴や皿を小さな目標にしない。

## 3. 粒子・音・振動の共通規則

粒子はKenney Particle Packの**`PNG (Transparent)`**から指定ファイルだけを使う。黒背景版をアルファ素材として読み込まない。ループする大きな爆炎で操作領域を塞がない。全ての粒子・金貨・破片は非操作物、得点判定なし。

Pは接触/成功位置。+Zがプレイヤーから離れる方向。指定した円錐方向へ粒子を出す際、個体iの角度を`2πi/N`として等間隔にし、毎回同じ構図を基準にする。見せる粒子が手前へ飛ぶ乱数は使わない。粒子の透明度は生存前半1、後半に0へ直線減衰。特記なければ空気抵抗なし、重力Y=-2.0m/s²。粒子サイズは直径。

接触の瞬間に0.045秒だけ対象の色を通常色の1.15倍にする。頭や手の動きを止めるヒットストップはなし。コントローラー振動は通常0.18/0.035秒、帯0.28/0.055秒、皿捕捉0.10/0.025秒。対応しなければ省略可。音・視覚を必ず残す。

## 5. 使用音源

ファイルの所在は06とasset_manifest参照。gainは元ファイルのピークを-1dBFSに正規化した後の相対dB。ピッチ1が原速。マスター初期値-6dB、利用者の音量設定を用意する。以下の音源選定は固定するが、今回は試聴していない。実装時に再生して欠落・破裂音・クリップを確認し、未試聴なら報告に残す。別音源へ無断で差し替えない。
