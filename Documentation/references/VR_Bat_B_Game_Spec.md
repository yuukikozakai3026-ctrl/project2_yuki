版：1.1（エージェントレビュー反映）／作成日：2026年9月28日

## 1. この仕様書で決めること

プレイヤーが何を見て、どう動き、何が起きるかを定める。開発環境、プログラム構成、物理計算の方法、制作手順は扱わない。

B案の中心は「来た物を見て、バットの扱いを切り替えながら対処する忙しさ」。制限時間内に多く処理する。普通のボール、ケーキ、爆弾、銃弾、宝箱の5種類だけを扱う。

### 合意済みの条件

- 普通のボールは打つ。
- ケーキは皿を下から受け、隣へ置く。
- 爆弾は台上で転がし、穴へ落とす。思いどおりに当たらず、あたふたする物理的な遊びも残す。
- 銃弾は複数を一つのまとまりとして出し、効率よくまとめてバットへ当てる。
- 宝箱は殴って開けるボーナス。派手な演出を重視する。
- 速度や力による成功・失敗・得点の判定、精密な打球方向、小さい箇所への狙いは要求しない。
- 銃弾のまとまり以外で、別アイテムが意図せず一振りに巻き込まれる状況は作らない。
- 今回はVR実機テストを行わず、PCの自動プレイで想定体験を示す。

### 今回具体化する決定

90秒の挑戦、その前の時間無制限の体験導入、手の届く作業台、各処理の時間・得点・失敗時の動きを定める。数値は初版の体験目標であり、実機で最適化済みの値ではない。毒瓶、お金単体、魔法玉、宝箱のてこ開け、防護板は初版に含めない。

## 2. 一回の遊びと得点

初回は5種類を一つずつ体験する。その後、舞台の時計が起動し、3つのランプが順に消えて90秒の挑戦が始まる。

一つの対処が成功・失敗のどちらかで終わると、次の物の予告へ進む。早く片付けた分だけ、多くの物に挑戦できる。手早さはこの進行で報われ、腕を速く振った値を得点へ換算することはない。

| 対象 | 成功 | 得点 |
| --- | --- | --- |
| ボール | バットへ当てる | 10点。金色の帯なら20点 |
| ケーキ | 下から受け、配膳台へ置く | 50点 |
| 爆弾 | 導火線が尽きる前に廃棄穴へ落とす | 40点 |
| 銃弾 | 弾をバットへ当てる | 1個10点。まとまり全部なら追加20点 |
| 宝箱 | 3回の別々の打撃で開ける | 60点 |

失敗による減点、ライフ、途中のゲームオーバーはない。失敗で得点機会と時間を失うが、すぐ次へ戻れる。コンボ倍率、得点からの時間購入、専用のスキップ操作は初版に設けない。

手間のあるケーキと爆弾には、普通のボールより高い成功報酬を設定する。早期失敗は次の課題へ進め、同じ種類を必ず成功するまで強制しない。このため意図的な失敗で一部の種類を飛ばすこと自体は可能。成功を目指す方が十分に報われる得点配分かは、仕様上解決済みとはせず体験評価項目に残す。

時計は現実の時間で進み、スローでも止まらない。0になったら新しい物の供給を止める。予告だけで未発射の物は出さず、発射済みの一課題は、接近時間を含めてその課題本来の期限まで続ける。終了時だけ別の短い上限を加えない。猶予中の得点も結果へ含める。画面の時計は「最後の1つ」に変わり、残りがマイナスになったようには見せない。

結果には総得点と、種類別の成功数を表示する。銃弾は「弾群の完遂数」と「弾の命中数」を区別する。AとBの点数は得点規則が違うため、数値で直接優劣を比較しない。

## 3. 舞台とバット

明るい玩具工場の対処台。中央にボール・銃弾・宝箱が来る空間、その下に爆弾が転がる浅い台を置く。ケーキの受け取りは中央寄り、配膳台は利き手側のすぐ横。爆弾の廃棄穴は作業台の反対側の端に置く。

| 場所 | 見た目と役割 |
| --- | --- |
| 中央の空間 | 普通の打撃と弾群処理。物が最も見やすい背景 |
| 手前の作業台 | 爆弾が転がる場所。浅い縁があるが、自動で穴へ流れる溝はない |
| 横の配膳台 | 大きい平らな面と、ケーキ皿と同じ模様。置くと受取口が開く |
| 台端の廃棄穴 | 爆弾より十分広い開口。縁に奥向きの案内灯と排気筒 |
| 正面奥の得点板 | 左に得点、右に残り時間。物の経路より上 |

すべて立ち位置から届く範囲とし、反対側へ回り込む、床へ深くかがむ、足を踏み出す動作は課さない。配膳の横移動は目安40cm。作業台の高さは本人の腰から肘の間に合う。机へ実際に手をついたり、体重を預けたりする動作は不要。

接触地点は正面から左右35度程度まで。初版は背後からの供給をしない。四方からの飛来は、初見の操作が確認できた後の拡張候補として扱う。利き手に応じて左右を反転できる。

バットは普通の棒状の形で、手に持った時から見える。打撃部分に金色の幅広い帯を置く。帯を狙う評価は普通のボールだけ。ボールが来る間だけ帯を明るく点灯し、それ以外の課題では周囲と同じ明るさへ戻す。ケーキ、爆弾、銃弾、宝箱で細かい位置を狙わせない。

プレイヤーの手とバットは一緒に動き、物を扱うために勝手に手の位置を動かさない。手首だけを極端にひねる、両手を指定の間隔で厳密に固定する条件はない。

実物の机がないため、手が仮想の台へ入り込む可能性はある。その場合もバットは手への追従を優先し、重なった台面を半透明の網目で局所的に知らせる。台の裏側から爆弾を押し上げる接触や、床下から物を処理する接触は成功にしない。バットを台の上へ戻せばそのまま再開でき、重なりだけで失点しない。

## 4. 共通の予告・スロー・進行

次の物は、対応する投入口が開き、約0.8秒の音と動きで予告される。その時点でシルエットを見せる。色を覚えるだけの分類にしない。

発射からスローへ入るまでの通常の接近部分は、各種類とも約1.4～1.8秒を基本とする。ケーキの風船、爆弾の着地、宝箱の鎖など、種類を判断する形をこの間に見せる。

打つ・受ける対象が接触範囲へ近づいた時、自動で短いスローへ入る。プレイヤーの手と頭は通常どおり動かせる。飛来物の進み方は約1/5を基準とする。

| 対象 | スローの区間 |
| --- | --- |
| ボール | 接触直前、実時間約0.9秒まで。当たるか通過したら終了 |
| ケーキ | 接近の最後から受け取り待ちへ移る短い約0.8秒。その後の受取待ちと配膳は通常の時間感覚 |
| 爆弾 | 作業台へ着く直前の約0.8秒。台へ降りたら解除し、導火線が燃え始める |
| 銃弾 | 一まとまりの全弾を一緒に、約1.0秒の接触機会へ入れる。最初の一発を弾いても残りのスローは継続 |
| 宝箱 | 最初に打撃範囲へ来る約0.8秒だけ。留まった後の連打は通常の時間感覚 |

表の秒数は、バットで無理なく届く範囲での接触機会の目標値。対象がまだ打撃範囲に残っているのに、秒数だけを理由に突然通常速度へ戻さない。銃弾は全弾が同じ時間進行を保つ。

スローに入る時は空気音が低くなり、対象の輪郭が少し明るくなる。画面全体の暗転や、手の遅れは起こさない。

一課題が終了するまでは、次の課題の接触対象を出さない。ボールと爆弾の同時処理などは初版で要求しない。銃弾だけは一まとまり全体で一課題。処理後は約0.6秒の余韻を置き、次の予告へ移る。

## 5. 普通のボール：打つ

### 来方

白い大きめの野球ボールが直線で来る。直径の目安は14cm。頭や胴体そのものを狙わず、バットを出せる空間を通る。

### 成功と失敗

バットのどこかへ接触すれば成功。金色の帯なら上乗せ得点と演出を付ける。バットを置いて接触させても成功し、最低スイング速度は設けない。打球方向は奥の回収ネットへ向くようにまとまり、精密な打ち分けはしない。

見逃すと後方のネットが受け止め、短い音だけを返す。身体に当たったダメージや視界の揺れはない。

### 演出

通常成功でも澄んだ打撃音、短い軌跡、小さい衝撃輪を出す。金色の帯なら、金色の輪と少し厚い音を追加する。

## 6. ケーキ：下から受けて置く

### 形で伝えること

柔らかい大きなケーキが、幅のある硬い皿に載って来る。皿の下面は大きく開いた浅い鞍形で、細い溝へ差す必要はない。皿全体を下から支えられる。ケーキ本体には受けるための印や狙い点を付けない。

横の配膳台には同じ皿の輪郭があり、受け取り中だけ縁が穏やかに点灯する。置く先を文字で説明しなくても、同じ形の組み合わせとして伝える。

### 来方と操作

風船付きの皿が浅い山なりで降り、目の前の届く高さへ来る。最初の接近が終わると、風船が支えて通常4秒まで受け取りを待つ。受取待ちの開始から配膳完了まで、全工程の期限は8秒。受け取りで時計をリセットしない。

バットを皿の下へ差して支えると、皿側の幅広い留め具がバットに沿って閉じ、風船が離れる。その瞬間に小さく沈んで安定する。速度・力・水平角度の厳密な条件は使わない。

載せた後は、皿側の支持具が皿を安定させる。バットを傾けても、皿は大きく傾かず、破損・脱落しない。手とバットそのものの姿勢を勝手に直すことはしない。プレイヤーはそのまま横へ運び、配膳台へ皿を近づけて下ろす。台が皿を受けると留め具が開き、ケーキが奥へ引き込まれて完了。

受取待ちでは風船がゆっくりしぼみ、受取後は配膳台の8個の縁灯が、受取待ちから数えた残り秒数に応じて消えていく。残り2秒だけ受取口のベルが短く鳴る。突然理由なく回収される見せ方にしない。

### 失敗

受取前に上や横から柔らかいケーキ部分を叩くと、ケーキが潰れて皿ごと回収される。皿の縁へ偶然触れただけでは即失敗にせず、皿が少し傾いて持ち直す。バットを下へ回す余地を残す。受取後は、傾けた自分のバットとの接触を理由にケーキを壊さない。

受け取り期限を過ぎると風船が萎んで皿が回収トレイへ落ちる。配膳期限を過ぎると皿を舞台側が回収する。失敗のクリームは顔や視界へ貼り付かない。

### 演出

受け取り成功は皿の「コトン」、ケーキの柔らかい揺れ、留め具の「カチッ」で伝える。配膳成功は受取口の小さなベル、皿模様の点灯、奥の小さな観客の喜びで伝える。置いた後に報酬を拾う操作はない。

### 初登場

本人の最初の皿は受取も配膳も時間無制限で待つ。すぐに対処が始まらなければ、奥の機械バットが別の皿を下から受け、近くの台へ置く短い実演を背景で見せる。本人の対象を取り上げたり、実演が終わるまで操作を禁止したりしない。操作の字幕や矢印への追従は要求しない。

## 7. 爆弾：台の上で転がして穴へ落とす

### 形で伝えること

黒い丸い爆弾、見える導火線、台に開いた大きな廃棄穴。Aの星印の花火弾と区別し、こちらは接触で爆発せず、導火線が尽きると爆発する。

直径は目安22cm。穴は爆弾の直径の約2倍を基本とし、精密な狙いを要求しない。台の端には浅い縁がある。中央に大きな障害物や迷路は置かず、穴へ向かう経路を見渡せる。

### 来方と操作

横の投入口から台へ転がり込む。着地後、導火線が8秒かけて燃える。バットの長い側面や先端で触れ、転がして穴へ落とす。継続的に押しても、何度か当て直してもよい。

台は基本的に水平。爆弾は接触した場所・押した方向・壁との衝突によって転がり、手を離すと徐々に減速する。自然に見える転がりを持つアーケード挙動として扱い、一度触れた時に弾き出す勢いは一定の範囲へ揃える。バットの振りの速さを変えても、同じ接触を強打や弱打に分類せず、飛び出す勢いの差で有利不利を付けない。

バットを当てたまま静止しても、繰り返し加速はしない。継続して押す場合は、見えるバットの移動に応じて爆弾が動く。バットの移動速度を追加の勢いとして加えない。

一方、球形の物として、端をかすめると横へ逃げる、台の縁で跳ね返る、穴の縁へ当たって転がり直す、といった出来事は残す。バットが目で見て外れていれば、押したことにはしない。自動で穴へ吸い込む、見えないレールで一直線に送ることはしない。

台上の遊びなので、爆弾が高速で顔へ飛び出したり、床へ落ちて追いかけさせたりしない。届かない所へ挟まった場合は台が小さく揺れて中央へ戻す。この復帰は導火線が残っている間に行い、動かせないまま必ず失敗する状態を作らない。

### 成功と失敗

穴へ落ちた瞬間に成功。穴の縁が閉じ、約0.5秒後に奥で「ドン」と鳴り、排気筒から煙が上がる。落とした安堵と爆発のタイミングを一組で見せる。

期限になると、作業台全体の防爆覆いが自動で閉じ、内部で爆発して回収する。プレイヤーへ突然大きな閃光を浴びせたり、視点を揺らしたりしない。失敗後の停止は約1秒以内を目標とする。

### 初登場

導入の最初の爆弾は導火線が消えており、本人は無制限で試せる。動き始めなければ奥の機械バットが別の一個を台の穴へ押し、排気筒から煙が出る短い実演を背景で見せる。次に、例外として導火線付きの爆弾をもう一個だけ出す。こちらは本番と同じ8秒で、成功・失敗のどちらでも次の種類へ進む。全体の90秒時計はまだ始めない。

## 8. 銃弾：一まとまりをまとめて弾く

### 来方

玩具の発射器に2～4個の大きな弾が並んで見える。初回は2個、本番の基本は3個、後半だけ4個にする。細く見えない弾は使わず、直径の目安は12～14cmとする。

弾は一つの短い直線、または緩い斜めの列として、一緒に近づく。まとまりの全幅は目安45～60cm。頭の左右へ散開する、バット一本では届かない幅へ広げる、高低を大きく離す配置は使わない。

各弾はほぼ同じ奥行きで接近し、握り部分を除いたバットの見える打撃部分で、まとまり全体を覆える寸法に収める。画面上だけ重なって見え、実際には前後へ大きく離れている配置はしない。

弾群全体が一回のスローに入り、最初に一つを弾いても、残りは同じ遅さで進む。一発が当たった瞬間に残りだけ急加速することはない。

### 操作と評価

バットの長さを列へ合わせてまとめて当てても、薙ぎ払う動きで順に当ててもよい。横持ち・縦持ちなどの正解姿勢は設定しない。バットの見えている範囲に実際に触れた弾だけが弾ける。

何度か当て直してもよい。振った回数による減点はなく、一発ずつを完全に別課題として待たせることもしない。短い接触機会の中でまとめて処理できれば、全弾ボーナスと一斉の金属音が得られる。

バットの金色の帯だけを狙う条件はない。個々の弾を小さい点として追わせない。全弾のまとまりを見て、バットを置く場所と通し方を選ぶ。

### 成功・取り逃し・演出

一発ごとに小さな火花と「キン」という音。短い間に複数が当たると音が重なり、全弾成功で澄んだ締めの音が鳴る。各弾は自動で奥側へ逸れ、身体へ跳ね返らない。

一部を逃しても当たった弾の点数は残る。取り逃した弾は後方の受け板が吸収する。減点・負傷・視点の揺れはない。弾群が全部当たるか通過した時に一課題を終える。

### 初登場

投入口に二つの弾が並ぶのを見せ、本人へ広めのスロー機会で出す。最初に取り逃した場合、次の本人の試行を妨げない位置で、機械バットが二発へ触れて二つの火花を出す短い実演を見せる。以後は列を少し傾けても、特定の姿勢を暗記させない。

## 9. 宝箱：殴って開けるボーナス

### 来方と形

太い鎖に吊られた木箱が、振り子のように前へ来て、バットが届く場所へ留まる。箱は目安45cm角で、箱全体が打つ対象。錠前や特定の角は狙わない。

### 操作

別々の3打で開く。一打目で木の留め板が外れ、二打目で大きくひび割れ、三打目で蓋が跳ねて中身が噴き出す。速度や力は問わない。

一打の後は箱が少し奥へ揺れて戻る。バットを箱から十分離して、もう一度触れれば次の打撃となる。接触しっぱなし、表面での細かな震え、一振りの細かな再接触を何打にも数えない。目安はバットを箱から約15cm離してからの当て直し。箱の揺れそのものが回数を稼ぐことはない。

離す条件を実際に満たし、次の打撃を受け付ける状態になった時、残った留め板が短く光り、箱が小さく軋む。単に箱が戻っただけでは光らない。接触したままなら、留め板は淡く光って次の打撃を待つ。箱の表面をこするだけで反応が増えない理由を、壊れた状態と次の点灯で伝える。

一度に必要な操作を文章で説明せず、壊れ残った板とひびで「もう一度」を伝える。最初の到着以外はスローにせず、好きなリズムで叩ける。

### 成功と期限

3打目で60点。金貨・宝石・紙吹雪が奥と上へ広がり、最後に一つ大きな宝石が光る。金貨を拾う追加操作はない。通常の処理より華やかなご褒美にする。

本番では到着から8秒で鎖が箱を回収する。吊り金具の8個のランプが一つずつ消え、最後の2秒で巻き上げ機が低く鳴り始める。開け切れなくても失敗ブザーを鳴らさず、残った箱を奥へ運ぶ。途中の打撃に得点はない。導入では期限を設けない。

## 10. 初見の導入とさりげない補助

初回は「ボール→ケーキ→導火線なしの爆弾→導火線付きの爆弾→銃弾2個→宝箱」の順。導火線付きの爆弾だけは、本番と同じ個別期限を体験する段階として追加する。長い操作説明画面、確認テスト、強制的に手を動かす案内は使わない。

| 対象 | 言葉の代わりに伝えるもの |
| --- | --- |
| ボール | 機械バットの一打と、金色の帯の光 |
| ケーキ | 硬い皿の広い底、下から受ける実演、同じ皿模様の配膳台 |
| 爆弾 | 転がる球、見えている穴、短くなる導火線、穴の奥の爆発 |
| 銃弾 | 発射前から見える弾の列、実演の複数の火花 |
| 宝箱 | 打つたびに外れる板、大きいひび、最後の報酬 |

まず本人の対象を提示する。自分で対処を始めた場合は実演を出さない。約3秒たっても対象を扱う動きが始まらない場合、または最初の試行で失敗した場合に、約2～3秒の実演を背景で一度だけ見せる。本人の対象と動きは止めず、実演への注視や終了待ちは要求しない。

導入では全体の時計を動かさず、失敗しても点数を失わない。各一回の成功で進み、失敗した場合は同じ段階をもう一度だけ試せる。二度とも失敗しても次の種類へ進む。導火線付きの爆弾は一回で次へ進む。成功するまで試験を繰り返さず、初回から舞台上の開始表示でいつでも本番へ移れる。

本番で同種の失敗が2回続いた場合は、次のその種類だけ、入口・受け皿・穴など目的に関係する場所を穏やかに点灯する。本番中に実演を挟んで時計を消費させない。操作を説明する文章や正解の姿勢を身体へ重ねる表示は追加しない。

## 11. 出現構成と忙しさ

基本の並びは「ボール→ケーキ→ボール→爆弾→銃弾群→ボール→宝箱→ボール」。この並びを繰り返し、成功するほど次へ進める。種類の違いを分からないままランダムで連発しない。

序盤30秒は中央寄り、銃弾は3個。中盤は物の入口を左右へ変えるが、対処する場所は届く範囲に留める。最後の30秒は銃弾が4個になり、爆弾の初期位置を穴から少し離す。導火線時間やケーキの期限を突然短縮しない。

忙しさは、打撃の後に受け取り、次に台へ視線を落として押し出し、その次に長いバットで弾群を受ける、という切り替えで作る。複数種類を同時に積み上げること、背後の物を探すこと、姿勢の細かい暗記では作らない。

## 12. 演出と情報の置き方

毎回、物の形が変わる・音が鳴る・処理先が反応する、の組み合わせで結果を伝える。

- ボールは澄んだ一打、ケーキは受けた重みと皿の音、爆弾は転がる音と穴の奥の爆発、銃弾は短い連続金属音、宝箱は段階破壊と報酬の噴出で区別する。
- 演出のために頭の視点を揺らしたり、強制的に対象を向かせたりしない。バットを持つ手の位置も勝手に変更しない。
- 煙・破片・金貨は奥側へ逃がし、次の接触地点を隠さない。毒やクリームによる全画面の視界妨害は入れない。
- 振動が利用できれば短い手応えを添えるが、それだけを成功の合図にしない。
- 得点板は奥の上部。処理中に読む必要はない。得点ポップアップは対象の少し上へ短く出す。
- ボールの金色の帯以外は、色だけで正解を区別しない。形、位置、動き、音で補う。

## 13. PC自動デモ

起動後、PC画面だけで「5種類の導入→90秒の挑戦→6秒の結果表示」を繰り返す。端に「自動デモ」と小さく表示する。主画面は一人称で、見下ろしが必要な爆弾だけ、頭を自然に少し下へ向ける。

各行動は想定した手と頭の動きとして見せる。ケーキは下へ差す、受けた皿を隣へ運ぶ、爆弾はバットを置き直して押す、銃弾は長い部分で列を覆う、宝箱は離してから当て直す。この動きと物の結果が対応していることを見せ、結果だけ成功する映像にはしない。

90秒は本番の挑戦時間であり、デモ一周の長さではない。自動デモの導入は約40～50秒、最後の一課題の猶予と結果表示を含む一周は約2分半を想定する。デモの都合で人の導入を強制的に早送りしない。

本番の見せる場面は、以下の時間帯へ割り当てる。課題の途中で映像だけを飛ばさず、実際の供給・接触・結果の順で収まることを成立条件とする。

| 本番の時間帯 | 見せる場面 |
| --- | --- |
| 0～35秒 | 5種類を一度ずつ。ケーキ配膳、爆弾の当て直しから成功、弾群の全弾成功、宝箱の開封を含む |
| 35～65秒 | 普通の成功を続けつつ、弾群で一発だけ取り逃す。ボールの通常成功と金色の帯の成功を比べる |
| 65～90秒 | 爆弾が期限切れになる一回を含め、失敗後に次へ復帰する。終了直前に新しい実演は挟まない |

一周で必ず見せる場面は以下とする。

1. ボールの通常成功と、金色の帯での成功。
2. ケーキの受け取りから配膳まで、一続きの成功。
3. 爆弾がバットの端をかすめて横へ逃げ、当て直して穴へ落ちる成功。
4. 銃弾群をまとめて処理する成功と、一発だけ逃して残りの点が入る場面。
5. 宝箱が三段階で壊れ、中身が噴き出す場面。
6. 一度だけ爆弾の期限が尽き、覆いの中で安全に回収され、次へ戻る場面。

自動デモでは、不自然な瞬間移動、成功位置へバットが吸い付く動き、台や物を突き抜ける手の経路は使わない。実際の人が台へ入り込んだ時は、第3節の重なり表示と復帰の扱いに従う。PCデモが予定どおり動いたことを、人間のVR操作が検証済みである根拠にはしない。

## 14. この版の確認基準

- 対処方法が文章なしでも、対象と舞台の形・短い実演から推測できる。
- ケーキの受け取りは皿底全体、爆弾の穴と銃弾のまとまりは大きく、宝箱は全体が対象である。
- 各期限や接触機会の内に同じ接触が成立した場合、バットの速度で結果や得点が変わらない。
- 爆弾には狙いどおりにならない転がりがあるが、見える接触を無視したすり抜けはない。
- 銃弾のまとまり以外に、別アイテムを意図せず同時処理しない。
- 失敗が次の成功を妨げる長い罰にならない。
- Aと比べて、バットの使い方を切り替える場面が明確に見える。
- 苦手な物を意図的に失敗して飛ばす遊びが得点面で支配的にならず、対処の成功を狙う意味がある。
