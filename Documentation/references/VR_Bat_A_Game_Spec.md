# VRバットゲーム A案 ゲーム仕様書

版：1.1（エージェントレビュー反映）／作成日：2026年9月28日  
対象：比較用プロトタイプと、その体験を示す自動デモ  
状態：会話で合意した方向を基に、今回の仕様書で挙動・演出・導入を具体化した初版

## 1. この仕様書で決めること

プレイヤーが何を見て、どう動き、何が起きるかを定める。開発環境、プログラム構成、物理計算の方法、パッケージ、制作手順は扱わない。

A案の中心は「来た物をバットで捉えた瞬間の爽快感」。B案と違い、アイテムごとの対処方法は覚えなくてよい。見た目が何であっても打つ。打撃位置を合わせる余地は残すが、振る速さ・力・打球方向の精密な調整は評価しない。

### 合意済みの条件

- AとBは別のゲーム案として比較する。
- Aは打撃を中心とし、アイテム差は主に演出と多少の飛び方・到達時機の差に留める。
- 打つ直前に自動でスローになり、バット上の良い位置を分かりやすく強調する。
- バットを速く振る、弱く振るといった判定は採用しない。
- 演出は遊びの中心として作る。
- 今回はVR実機テストを行わず、PCで見られる自動プレイを用意する。将来のVR操作と同じ体験を想定する。

### 今回具体化する決定

比較する見た目は、普通のボール・ケーキ・爆弾・銃弾・宝箱の5種類。Aではすべて一打で処理する。90秒の得点挑戦と、その前の短い時間無制限の導入を設ける。背後からの奇襲はなく、正面と左右斜めの見渡せる範囲を使う。数値は初版の体験目標であり、実機で確認済みの最適値ではない。

## 2. 一回の遊び

1. バットを手に持つ。舞台の機械が起動し、最初のボールが目の前へ来る。
2. 無制限時間の導入で、当てることと、金色の帯で捉えた時の違いを体験する。
3. 舞台の時計が点灯し、3つのランプが順に消えて90秒の挑戦が始まる。
4. 一個ずつ来る物を打つ。処理が早ければ次も早く届き、打てる個数が増える。
5. 残り時間が0になったら新しい投球を止める。予告だけで未発射の物は出さない。発射済みの一個だけは普段どおりの接触機会が終わるまで続け、得点へ含める。終了時だけ短い別期限を加えず、時計は「最後の1つ」の表示へ変わる。
6. 結果には総得点、打てた個数、良い位置で捉えた個数を表示する。

ミスによる途中終了、体力、死亡はない。失敗しても次の一球で立て直せる。コンボ倍率や残り時間の加算は初版に入れない。

## 3. 舞台・視点・届く範囲

舞台は明るい玩具のバッティング施設。背景は彩度を抑え、飛来物とバットを最も読み取りやすくする。正面遠方に大きな得点板、その左右に投球口を置く。

- 接触位置は原則として正面から左右35度程度まで。肩より高い打撃、深いしゃがみ、足運びは要求しない。
- 投球口はさらに外側に置けるが、最後の接触地点は手の届く正面域に収まる。
- 頭・顔・胸そのものを狙わず、バットを出せる手前の空間を通る。見逃した物は後方の回収ネットへ入る。
- 体格に合わせて接触位置と舞台の高さが合うことを体験の前提とする。実物の台にもたれる動きは要求しない。
- 利き手は左右を選べ、バットや投球位置はその向きに合わせる。片手でも成立し、二本のコントローラーの厳密な接続姿勢は要求しない。
- VR視点は本人の頭の動きに従う。成功してもカメラを振る・勝手に打球を追う・視野を急に狭める演出は行わない。

会話に出ていた四方からの飛来は、この初版では正面・斜めからの供給へ絞る。初見で背後への振り向きや画面外探索を課題にしないための、今回の仕様決定である。

## 4. バットと打撃

バットは形が分かる素直な金属バット。握り部分は濃色、打撃部分は明色。先端寄りに幅広い金色の帯を置き、そこを「よい当たり」の領域として常時見せる。目安はバット全長約85cm、金色の帯の長さ約25cm。これは小さな一点を狙う課題にしないための広さである。

| 接触 | 結果 | 得点 |
| --- | --- | --- |
| 金色の帯に接触 | よい当たり。厚い打撃音と金色の衝撃輪 | 20点 |
| それ以外のバット部分に接触 | 通常の成功。十分に気持ちよい音と破壊・飛散 | 10点 |
| バットに接触せず通過 | 見逃し。後方のネットが受け止める | 0点 |

バットへ当たれば成功する。速さ、力、角速度、最低スイング速度、一定方向へ振る条件は設けない。構えたバットに物が当たっても成功する。置いて当てる遊び方を禁止するための隠れた減点は設けない。

最初の接触でその物の結果を確定し、飛び出した破片や打球に再度触れても追加得点は発生しない。通常成功とよい当たりで、必要な操作や飛ばす方向は変わらない。よい当たりは音・光・得点の上乗せで伝える。

打球は接触後、供給側の奥へ向かう分かりやすい軌道で飛ぶ。方向を狙う課題はない。速く振った時だけ遠くに飛ぶといった差も作らない。

## 5. 接近とスロー

各投球口は発射の約0.8秒前に開き、短い光と音で次の場所を伝える。発射から接触機会までの通常部分は、1.4～2.0秒を基本とする。後半も予告は省かない。

飛来物が打撃範囲の直前へ入ると、一回だけ自動でスローになる。スロー中は飛来物の進み方が通常の約1/5になり、実時間で約0.9秒、位置を合わせる余地を作る。プレイヤーの頭と手は普通に動かせる。

約0.9秒は、バットで無理なく届く空間に物がある間の接触機会の目標値。遠くにいる待ち時間ではない。対象がまだ打撃範囲内に残っているのに、時間上限だけを理由に急加速することはない。

- 入る瞬間に空気音が低くなり、飛来物の輪郭とバットの金色の帯が少し明るくなる。
- 完全停止はせず、物は接触地点へ進み続ける。
- 当たったらすぐに通常の時間感覚へ戻り、打球や破片が勢いよく飛ぶ。
- 見逃しで打撃範囲を抜けても終了する。同じ物で繰り返しスローを発動しない。
- 90秒の時計はスロー中も現実の時間で進む。

スローは色だけで伝えず、動き・音・輪郭の変化を併用する。残像は軌道の後ろだけに短く出し、当たる位置を隠さない。

## 6. 5種類の飛来物

### 普通のボール

白い大きめの野球ボール。直径の目安は14cm。素直な直線で飛び、初見の基準になる。

接触すると「カキン」という澄んだ音が鳴り、短い白い軌跡を残して遠方のネットへ飛ぶ。よい当たりでは金色の衝撃輪と、音の高い成分を上乗せする。球の正面に的や細かな命中点は描かない。

### ケーキ

皿なしの一切れのケーキが、浅い放物線で飛んでくる。上面や側面など、どこに当てても同じ成功。受け止める、壊さず扱う、軽く打つ条件はない。

接触した瞬間にスポンジ・クリーム・イチゴが奥へ大きく飛び散る。甘い破裂音と短い紙吹雪のような粒で、柔らかい物を打ち抜いた感じを出す。クリームは視界やバットへ残らず、次の一球を遮らない。

### 爆弾

星の印と金色の帯が付いた玩具の花火弾。Bの導火線式爆弾と見分けられる外観にする。Aでは危険物ではなく、打って遠くで爆発させる対象。

ボールと同じように正面へ来て、接触すると奥へ飛ぶ。十分遠ざかったところで、丸い花火と低い破裂音を出す。プレイヤー付近で爆発しない。見逃した場合も後方の回収筒へ入り、安全に消える。打つか避けるかの判断は要求しない。

### 銃弾

銃口ではなく玩具の発射器から、一個の大きな丸い金属弾が飛ぶ。小さく鋭い実弾の外観にはせず、シルエットをはっきり見せる。接近の通常部分だけ少し短めだが、打つ直前のスローの長さは他と同じ。

接触時に「キン」という音と短い火花を出し、奥の金属板に当たってもう一度鳴る。一度に複数は出さない。Bの弾群処理と区別する。

### 宝箱

小さく軽そうな木箱。浅い山なりで飛び、一回当てれば開く。連打や錠前への狙いは不要。

接触で蓋が跳ね、金貨・宝石・光が奥側へ噴き出す。報酬を手で集める追加操作はない。他の物と同じ10点／20点で、見た目の華やかさを担当する。Aの得点規則を種類によって複雑にしない。

## 7. 出現順と難しさ

初版の繰り返しは「ボール→ケーキ→ボール→爆弾→ボール→銃弾→ボール→宝箱」の8個を基本にする。次の物は、前の物の成功または見逃しが決まってから予告する。成功演出の破片が残っていても、次の対象と取り違えない薄さへ先に変わる。

| 時間 | 変化 |
| --- | --- |
| 0～30秒 | 主に中央。同じ高さを中心にし、当たる楽しさを確かめる |
| 30～60秒 | 左右斜めと、腰から胸下までの高さの変化を加える |
| 60～90秒 | 通常部分の到達時機に変化を付ける。最後のスローの長さと当てやすさは維持する |

高速化だけで難しくしない。カーブ、スライダー、消失、偽物、ジグザグなどの魔球は初版に入れない。アイテムごとに異なる操作は追加しない。

## 8. 初見で自然に分かる導入

長い文章、操作を読んで確認ボタンを押す画面、矢印に沿った厳密な動作の強制はない。舞台の動きと、成功に対する反応で伝える。

1. バットを持つと、金色の帯へ光が流れる。正面の投球口だけが開く。
2. 最初の一球は中央へゆっくり来る。スローの接触機会は通常の約2倍。どこかへ当たれば十分な成功演出を出す。この導入中は時間と得点の競争をしない。
3. 次の一球では、ボールの光とバットの金色の帯が同じリズムで脈打つ。帯に当たれば強い祝福が出るが、帯を外しても先へ進める。
4. 皿なしケーキを一度見せ、当たると奥へ飛び散ることを体験する。Bの皿付きケーキとの違いが接近時から見える。
5. Aの花火弾を一度見せ、打った先で遠くに花火が咲く。爆弾を避けるゲームと誤解させない。
6. 舞台の時計が起動して本番へ進む。

各段階は、バットのどこかへ一度当てたら次へ進む。金色の帯への成功は進行条件にしない。同じ段階で2回見逃した場合、正面奥の機械仕掛けのバットが同じ物を一度打って見せ、その後もう一度だけ広い接触機会で試せる。その一回が見逃しでも次の段階へ進む。成功するまで無制限に試験を繰り返す導入にはしない。

実演中も本人の手を動かしたり、正解動作をなぞらせたりしない。本番中に苦手そうな場合は投球口と金色の帯の光を少し強調するだけとし、時計を進めたまま実演を見る時間を挟まない。

導入は初回からいつでも、舞台上の大きな開始表示で省略できる。利き手選択や開始・再挑戦の短い文字は使用してよい。

## 9. 画面・音・成功演出

得点板は正面奥、打撃地点より上に置く。得点は左、残り秒数は右。視線中央や飛来経路には文字を置かない。加点は接触地点の少し上へ短く出て、すぐ消える。常時の照準線や画面中央の説明パネルはない。

通常成功でも音・物の変形・短い光の3つを必ず返す。よい当たりは金色の輪と澄んだ音を追加する。全画面の白フラッシュ、視点の強制移動、長いヒットストップは使わない。振動を使用できる場合は短い打撃感を添えるが、振動がなくても結果が見て分かる。

ミスはネットの受け止め音と投球口の短い点滅だけで示す。大きな失敗文字、視界への汚れ、長いブザーで次の機会を邪魔しない。

## 10. PC自動デモの見せ方

起動後、PCだけで「初見導入→90秒の挑戦→6秒の結果表示」を繰り返す。映像上部の端に小さく「自動デモ」と表示し、人が実際にVRで操作した記録とは区別する。

90秒は本番の挑戦時間であり、デモ一周の長さではない。自動デモの導入は約20秒を想定し、一周は最後の一球の猶予を含め約2分になる。人が操作する導入の時間を、この見せ方の都合で強制的に切らない。

本番の最初の35秒で5種類を一度ずつ見せ、中盤で通常成功と金色の帯での成功を比べられる場面を置く。見逃しからの復帰は60秒までに一度見せ、最後の30秒は打撃の流れを途切れさせない。個々の投球と結果がこの時間枠に収まり、早送りの映像に見えないことをデモの成立条件とする。

視点はプレイヤーの一人称を基本とし、バットを合わせて当てる様子と、その直後の飛散を見せる。カメラは接近物へ緩やかに向くが、打球へ飛び移ったり、接触直前に別カメラへ切り替えたりしない。初期設定では小窓や開発用情報を重ねない。

デモは想定した頭・手の動きでプレイし、物へ接触した場面だけを成功として見せる。通常の当たりと、帯で捉えた当たりを両方含める。一周に1回はボールを見逃し、そのまま次へ復帰する。全物体の演出を少なくとも一度見せる。手首だけが不自然に移動する動き、瞬間移動、実際には触れていないのに成功する見せ方はしない。

自動デモが成立しても、人がVRで楽しく操作できることを確認した扱いにはしない。

## 11. この版の確認基準

- 初めて見た人が、読解なしに「来た物を打つゲーム」と理解できる。
- 5種類とも同じ打撃で成功し、A内に受ける・避けるなどの別ルールが混ざらない。
- 金色の帯を狙わなくても、打ったことに十分な音と見た目が返る。
- 接触機会の内に同じ接触が成立した場合、バットの速度によって結果や得点が変わらない。
- 物の輪郭・接触・結果が演出で隠れない。
- 失敗しても短時間で次を楽しめる。

## 12. レビュー記録

2026年9月28日、VR操作、初見体験、仕様の整合性を3名のエージェントが文面で確認した。以下を初稿から修正した。

- 最後の一球に短い別期限を設けず、通常の接触機会を保障した。
- スローの秒数を「届く範囲での接触機会」と定義し、範囲内での突然の加速を防いだ。
- 導入の終了を実際の成功・試行回数で定義し、初回から省略可能にした。
- Aの皿なしケーキと花火弾を導入で見せ、Bとの外観の違いを強めた。
- 本番90秒とデモ一周の長さを分けた。

修正版をVR操作担当・初見体験担当が再確認し、指摘した必須修正の反映を確認した。

このレビューは企画上の矛盾・負担・分かりにくさの点検であり、実際に遊んだ評価ではない。バットの長さ、物の見やすさ、金色の帯の狙いやすさ、片手操作の疲れ、実演への気づきは、今後のVR実機確認事項として残る。
